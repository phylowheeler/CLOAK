Directory containing the program used for benchmarking alignment filtering programs

### MSAscorer
Compares a test multiple sequence alignment to a reference and score the number of true positive, false positive, and false negative homologous pairs across the alignment.
Taken with permission from [Simon Whelan](https://github.com/simonwhelan/MSAscorer/tree/master).

To run MSAscorer, download this directory and compile using:
```
g++ -o MSAscorer Sequence.cpp MSAscorer.cpp
```
